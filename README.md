# CS Root

CS Root is a platform designed to help students practice and improve their understanding of core Computer Science subjects through structured problem solving and assignments.

The platform provides subject-wise questions created by teachers or administrators and allows students to submit their solutions online. Depending on the subject, submissions are evaluated either automatically or manually.

---

## Subjects

The platform currently supports the following subjects:

- Data Structures and Algorithms (DSA)
- Database Management Systems (DBMS)
- Operating Systems (OS)
- Computer Networks (CN)
- Computer Architecture (CA)

---

## How It Works

### Data Structures and Algorithms (DSA)

DSA problems work similarly to coding platforms such as LeetCode.

Students can:

- Read the problem statement
- Write code in the supported language
- Run sample test cases
- Submit their solution

The submitted code is automatically evaluated against predefined test cases, and the result is generated instantly.

---

### DBMS, Operating Systems, Computer Networks, and Computer Architecture

For theory-based subjects, students can:

- Read the question
- Upload their handwritten answer or document
- Submit their solution

Teachers or administrators review the submissions manually and assign marks and feedback.

---

## User Roles

### Student

- View available subjects
- Solve DSA coding problems
- Upload answers for theory subjects
- View submission history
- Check evaluation results

### Teacher / Admin

- Create and manage questions
- Manage subjects
- Add test cases for DSA problems
- Review uploaded answers
- Assign marks and provide feedback
- Manage students
